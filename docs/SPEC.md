# 用户确认的范围

首页延续今日概览与资源两个面板，卡片名称和描述分行，适配手机和平板。
搜索范围为网页、应用、书签；网页支持 Google/Baidu/Bing；站内检索名称、描述、分类、标签并有清空及空结果提示。
访客展示 IP（默认部分隐藏、可展开）、预计城市、运营商；天气按 IP 所在城市获取，可手选城市，失败回退默认城市且不伪造数据。
管理员登录；应用/书签增删改、图标、排序；分类/标签管理及排序；站名、Logo、问候语、页脚、引擎和默认城市设置；JSON 备份导入导出。
整页、概览、资源三处独立配置纯色/渐变/图片，支持本地上传和远程图片链接、位置、尺寸、遮罩，预览/替换/移除/恢复默认；卡片颜色/透明度/圆角可配。
晴空白/石墨黑/山岚自然绿三套主题，独立保留各主题背景覆盖。管理员配置全站默认主题，访客可本地切换预览。
Node.js + SQLite，本地图片目录持久化，提供 Docker 配置。管理员数据不得公开读取或通过静态服务下载；写入需登录，导入需校验且原子替换。
验收：登录权限、增删改持久化、图片上传、主题背景、搜索、定位/天气失败回退、多端浏览器。

不包括访问统计、搜索历史、多用户系统及对外部署。

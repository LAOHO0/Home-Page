# 设计准则

采用 ui-ux-pro-max 的语义色、44px 触控目标、键盘焦点、表单可见标签、加载和错误反馈、减少动态效果建议。搜索结果里的营销页构图及 React Native 专属规则不用于本项目。

晴空白：雾蓝背景、白面板、深蓝强调；石墨黑：炭灰背景、石墨面板、浅蓝强调；山岚：本地缓存的 Unsplash 山景照片、暖白面板、森林绿强调。
保留参考站概览+资源结构，增加轻量顶栏和访客状态；使用系统中文无衬线字体，数字等宽，4/8px 间距，卡片标题及副标题独立块级布局。
三个背景区独立覆盖，文字颜色可手选以适应图片；默认主题前景对比度至少4.5:1；尊重 prefers-reduced-motion。
